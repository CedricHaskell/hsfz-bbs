# 🎓 HSFZ BBS 华附论坛 · 功能介绍

> **网址：https://bbs.hsfz-bbs.cn**
> 华南师范大学附属中学自己的校园论坛 —— 学习、年级、球友、生活、交易，一个都不少！

## 🚀 快速上手

1. 打开网址，点右上角「注册」，选好你的年级提交申请；
2. 管理员核实姓名、学号及年级后批准账号；校友名单供审核参考，所有申请均需审核；
3. 登录后点「✏️ 发帖」，选板块、写标题正文、配上图片，发布！

## ✨ 特色功能

- **📷 发帖带图**：最多 4 张照片，自动压缩，图文并茂
- **🎖️ 头衔系统**：发帖回帖自动升级（新入校 → 校园新人 → 活跃同学 → 校园达人 → 传奇学长），表现优秀还有管理员授予的金色专属头衔
- **🖼️ 自定义头像**：上传喜欢的图片，告别默认小方块
- **👍 帖子互动**：回复、点赞、收藏，首页热门话题榜
- **📬 直达管理员**：「我的消息」发工单——申请头衔、提建议、举报内容，管理员逐条回复
- **🌙 深浅主题**：白天浅色晚上深色，一键切换
- **🔍 全站搜索**：帖子内容一搜即达
